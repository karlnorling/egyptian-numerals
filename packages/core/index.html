@egyptian-numerals/core

toSvg(value, options?)

Section titled “toSvg(value, options?)”

Returns an SVG string. value can be a number, bigint or decimal string.

Option Default Notes
size 100 Image height in pixels. The width follows from the number of signs.
color currentColor Colour of the signs. Takes a colour or a gradient.
background none Colour or gradient behind the numeral.
gap 16 Space between groups, in viewBox units. A sign is 60 tall.
padding 20 Space around the numeral, in viewBox units.
title the number Accessible name. false leaves it out and sets aria-hidden.

Throws a TypeError for text that isn’t a decimal number and a RangeError for NaN, Infinity or a bad option.

Colours and gradients

Section titled “Colours and gradients”

color and background take any CSS colour, or a gradient: linear-gradient(), radial-gradient() and their repeating- forms. A gradient spans the whole image, so a long number runs through every colour once.

Stops take percentage positions, and a stop with two positions (red 0 3%) makes a hard-edged band. Gradients can also be objects: { type: 'linear', angle: 90, stops: ['red', { color: 'blue', offset: 0.8 }] }. parseGradient(css) turns a CSS gradient string into that form.

Lower level

Section titled “Lower level”
  • parse(value) → { negative, integer, fraction }: the base-10 digits that get drawn, most significant first.
  • format(parsed) → the canonical decimal string.
  • digitSvg(digit, place?, options?) → one digit from 0 to 9 on its own. place picks the sign, from strokes (0) to Heh (6), and digit how many of it. Zero draws nfr.
  • BASE → 10.
  • fractionSvg(fraction) → one Egyptian fraction on its own.
  • egyptianFractions(digits) → the fraction after the point as 2/3 and unit fractions.
  • breakdown(value) → the signs a number is written with, group by group.
  • POWER_SIGNS, MOUTH, TWO_THIRDS and NFR → the sign drawings, with their Gardiner codes.
